## ⚡ التحميل والتشغيل الفوري على أي توزيعة لينكس

التطبيق مبني ومجهّز بالكامل في قسم [**Releases**](https://github.com/mosalah30688-gif/sirag-atlas-linux/releases/latest) بصيغة **`.AppImage`** يعمل على **Ubuntu, Debian, Linux Mint, Fedora, Arch, Manjaro, Zorin, Kali, Pop!_OS** بدون تثبيت:

1. **حمّل الملف الجاهز مباشرة:**
   - 🐧 [**تحميل النسخة المكتبية الكاملة المستقلة (`Sirag-Atlas-Seerah-x86_64.AppImage` — 80 MB)**](https://github.com/mosalah30688-gif/sirag-atlas-linux/releases/latest/download/Sirag-Atlas-Seerah-x86_64.AppImage) *(مبنية بـ Electron، لا تحتاج أي متطلبات مسبقة على الإطلاق)*.
   - 🪶 [**تحميل النسخة المحمولة فائقة الخفة (`Sirag-Atlas-Lite-x86_64.AppImage` — 3.2 MB)**](https://github.com/mosalah30688-gif/sirag-atlas-linux/releases/latest/download/Sirag-Atlas-Lite-x86_64.AppImage).

2. **امنحه صلاحية التشغيل وشغّله فوراً (أو دبل كليك من مدير الملفات):**
   ```bash
   chmod +x Sirag-Atlas-Seerah-x86_64.AppImage
   ./Sirag-Atlas-Seerah-x86_64.AppImage
   ```
   > *ملاحظة لتوزيعات Ubuntu 22.04/24.04 إن لم تكن مكتبة FUSE مثبتة:* شغّل `sudo apt install libfuse2t64` أو شغّله مباشرة بدون FUSE بالأمر: `./Sirag-Atlas-Seerah-x86_64.AppImage --appimage-extract-and-run`

## ✨ أبرز المزايا والأقسام التفاعلية الـ 11 (أوفلاين 100%)

- **🗺️ الأطلس الزماني-المكاني الحي ومُزامِن الوحي:** 18 محطة مفصلية مع شريط الزمن النبوي والآيات النازلة في قلب كل حدث و3 مستويات لعمق القراءة.
- **🐪 مسار الهجرة السرية (480 كم) وميدان فرسان السيرة:** تتبع يومي لرحلة الهجرة وأدوار خلية التخطيط + 12 تحدياً تفاعلياً وأوسمة ذهبية.
- **⚔️ المُشغّل التكتيكي للغزوات:** محاكاة طبوغرافية خطوة بخطوة لبدر وأُحد والخندق وخيبر ومؤتة وفتح مكة.
- **🕌 المخطط الهندسي التفاعلي للحرمين الشريفين:** تجوال تفاعلي داخل عمارة المسجد النبوي والروضة الشريفة ومعالم الكعبة المشرفة.
- **🧭 وضع المعايشة «لو كنتَ في ذلك اليوم»:** مجالس الشورى النبوية واستخلاص الحكمة القيادية والنفسية.
- **🌟 مجرّة الصحابة الكرام + 🌿 عمود النسب النبوي وساعة الشمائل اليومية.**
- **🎙️ ديوان القصائد الصحابية المسموع (أوفلاين بدون موسيقى) + 📖 معجم مواضع وغريب السيرة.**
- **💎 الهدي النبوي التطبيقي + 📜 المتحف النبوي ثلاثي الأبعاد (3D) + 🖼️ استوديو البطاقات الذهبية.**
- **🏅 ختمة السيرة في 30 مجلساً + إصدار الشهادة الذهبية المذيلة باسمك الكريم (`PNG` عالي الدقة).**
- **⚙️ مركز الإعدادات والتحديث المباشر بالإشعارات:** متصل تلقائياً بهذا المستودع لتنبيهك وتنزيل أي إصدار `.AppImage` جديد بضغطة واحدة!

## ⌨️ اختصارات لوحة المفاتيح لنسخة سطح المكتب

| الاختصار | الوظيفة |
|---|---|
| `Ctrl + K` | فتح البحث الفوري الشامل والمحفوظات |
| `Ctrl + ,` | فتح مركز الإعدادات وفحص التحديثات |
| `F11` | التبديل إلى وضع ملء الشاشة الملكي |
| `Alt + 1 .. 9` | الانتقال الفوري بين أقسام السيرة |
| `Alt` | إظهار/إخفاء شريط القوائم العربي المكتبي |

## 🛠️ البناء أو التشغيل من السورس (للمطورين)

```bash
git clone https://github.com/mosalah30688-gif/sirag-atlas-linux.git
cd sirag-atlas-linux
npm install
npm start              # تشغيل التطبيق مباشرة على سطح المكتب
npm run build:appimage # بناء ملف dist/Sirag-Atlas-Seerah-x86_64.AppImage
```
